# re-align — نظام تشغيل وكلاء الذكاء الاصطناعي للشركات

**منصة SaaS متعددة المستأجرين (Multi-tenant)، تشتغل فعلاً من أول سطر لآخر:**
وكيل ذكاء اصطناعي يفكّر → يكتب → يطلب موافقة بشر → ينشر → يُقاس → يُفوتر.

النسخة دي مبنية على **Python 3.13 + FastAPI**، وبتشتغل **بدون أي خدمة خارجية** من أول لحظة
(مزوّد LLM وهمي مدمج)، وتتحوّل لوضع الإنتاج الحقيقي بمجرّد ما تحطّ مفاتيحك في ملف `.env`.

---

## ١. أهم ٣ أسطر في حياتك

```bash
./scripts/start.sh            # بيظبط كل حاجة ويشغّل السيرفر
```

أو خطوة بخطوة:

```bash
cp .env.example .env          # انسخ ملف الإعدادات
python -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python scripts/seed.py    # يعبّي بيانات تجريبية
.venv/bin/uvicorn realign.main:app --host 0.0.0.0 --port 8000
```

بعدها ادخل على: **http://localhost:8000** واستخدم الحساب التجريبي:

| البريد | كلمة السر |
|---|---|
| `admin@re-align.app` | `Re-Align#Admin2026` |
| `demo@re-align.app` | `Re-Align#Demo2026` |

لو عايز السيرفر شغال طول الوقت:

```bash
make run          # uvicorn مع reload تلقائي
make test         # ١٧ اختبار
make seed         # بيانات تجريبية
make migrate      # ترقية قاعدة البيانات
make admin        # إنشاء مدير
```

`mock_channel` (تجريبي) · `telegram` · `webhook` · `email` · `rss` ·

### ٥٩ نقطة نهاية API + ٢٦ صفحة ويب

- `/api/v1/health` — فحص و`/health/ready` فحص جاهزية (DB + LLM + وكلاء + موصلات)
- `/api/v1/auth` — تسجيل، دخول، تجديد توكن، الملف الشخصي، تغيير كلمة السر
- `/api/v1/agents` — كتالوج الوكلاء، تشغيل متزامن/غير متزامن، حالة التشغيل
- `/api/v1/runs` — سجل التشغيلات مع التكلفة والخطوات
- `/api/v1/approvals` — طابور الموافقة البشرية (البوابة الوحيدة للنشر)
- `/api/v1/assets` — كل قطع المحتوى وحالاتها
- `/api/v1/integrations` — ربط وفك ربط واختبار كل موصّل
- `/api/v1/brand` — ملف البراند (الصوت، الممنوعات، الجمهور، الكلمات المفتاحية)
- `/api/v1/billing` — الخطط، الاشتراك، الاستهلاك، الفواتير
- `/api/v1/org` — المؤسسة، الأعضاء، الدعوات، API keys
- `/api/v1/admin` — لوحة الإدارة العامة (مؤسسات، kill switch، صحة النظام)
- `/api/v1/webhooks` — استقبال ويبهوكات الدفع (بتوقيع HMAC)

#### الواجهة (واجهة سينمائية داكنة)

- **لغتين بالكامل**: مبدّل لغة (العربية / EN) في كل صفحة، والاتجاه بيتقلب أوتوماتيك
  (`dir="rtl"` / `dir="ltr"`). كل نص جاي من كتالوج ترجمة واحد (`realign/web/i18n.py`)
  فيه **٦١٢ مفتاح** بالعربي والإنجليزي، وفيه اختبار آلي بيمنع أي مفتاح ناقص أو زيادة.
- **نظام سينمائي داكن** (`marketing.css`): خلفية `#050505`، أسطح `#111214` / `#17181B`،
  نص `#F4F4F5` / `#A1A1AA`، حدود `rgba(255,255,255,0.10)`، وأكسنت ثلجي مقيّد `#7DD3FC`.
  العمق بييجي من الإضاءة والحدود الرفيعة مش من الألوان الصارخة.
- **Hero سينمائي**: أشرطة ضوء فضية منحنية (SVG بـ blur متفاوت) بتنجرف ببطء (15-22 ثانية)،
  بارالاكس خفيف بالماوس على الديسكتوب بس، كشف سطري للهيدر، وgrid رفيع في الخلفية.
- **طبقة حركة كاملة** في `app.js`: nav بيتحول لسطح داكن بـ blur عند السكرول،
  scroll reveals مرة واحدة، تبويبات الـ feature showcase بالكيبورد، عُقد الـ workflow
  بتنور وتتقدم، وكروت عائمة. كله بيحترم `prefers-reduced-motion`، ولو الـ JS اتعطّلت
  كل المحتوى ظاهر وشغال (الكشف opt-in بكلاس `js`).
- **صفحات عامة جديدة**: `/product` (كتالوج الوكلاء الحقيقي من الـ registry)،
  `/pricing`، `/resources`، `/faq`، `/contact` (فورم شغال)، وصفحة **404** بالبراند.
- **الداشبورد بنفس اللغة البصرية**: tokens الـ `app.css` على نفس الباليت الداكن،
  فكل المنصة بتحس إنها حاجة واحدة.
- **أمانة في التسويق**: شريط الـ "Trusted by" بيعرض القنوات الحقيقية بس
  (جاهز / يحتاج مفتاح) — من غير عملاء ولا لوجوهات متخيلة، وديمو الـ workflow
  عليه شارة "بيانات تجريبية".
- **استضافة ذاتية كاملة**: خطوط Cairo و Inter متحمّلة جوه المشروع (مفيش طلبات لجوجل)،
  وكل أصول البراند متولّدة بالكود عن طريق `scripts/make_brand.py`.
- **نسيت كلمة المرور**: صفحتين (`/forgot-password` و `/reset-password`)
  بتوكن لمرة واحدة صالح ٣٠ دقيقة، متخزّن مشفّر (hash)، والصفحة بترد نفس الرد
  للإيميل المعروف والغريب (مفيش تسريب لحسابات العملاء).
- **النشر على Vercel أو Railway** (نفس الريبو يشغّل الاتنين):
  - Vercel: `api/index.py` + `vercel.json` + `runtime.txt` — الكود بيكتشف
    `VERCEL=1` لوحده ويقلب وضع serverless (تشغيل inline + bootstrap admin +
    cron endpoint). الدليل: `docs/VERCEL.md`.
  - Railway: `Dockerfile` + `railway.toml` + دليل `docs/RAILWAY.md`.
  - سيرفرك الخاص: `docker-compose.yml` + `deploy/nginx.conf` +
    `deploy/re-align.service`.
  - قاعدة البيانات في كل الطرق: Neon (Postgres) — بدعم `DATABASE_URL` أو
    الأربع متغيرات `PGHOST/PGUSER/PGPASSWORD/PGDATABASE`.

## ٣. ليـه النظام ده آمن يتباع للشركات؟ (الضمانات)

١. **عزل المستأجرين (Tenant isolation)** — كل جدول فيه `org_id` بمفتاح أجنبي حقيقي،
وكل استعلام مفلتر تلقائياً. اختبار `test_tenants_are_isolated` بيتأكد إن شركة ألف
مش قادرة تقرأ ولا تشوف تشغيلات شركة باء (بتطلع 404 مش 403، يعني ما بتعرفش إنها موجودة).

٢. **بوابة موافقة بشرية** — مفيش ولا وكيل يقدر ينشر حاجة لوحده.
النشر بيحصل **فقط** من `POST /api/v1/approvals/{id}/decide` بالقرار `approve`.
الاختبار `test_content_requires_human_approval` بيمنع أي تغيير يكسر القاعدة دي.

٣. **Kill switch** — مفتاح إيقاف عام (من الإعدادات) + مفتاح لكل مؤسسة.
لما يتفعّل: صفر إنفاق، وكل تشغيل يطلع `skipped`. الاختبار: `test_kill_switch_blocks_execution`.

٤. **حدود إنفاق ثلاثية** — ميزانية شهرية بالمليم · ميزانية لكل تشغيل · حدّ يومي للتشغيلات.
أول ما الرصيد يخلص → التشغيل يتخطّى (`test_exhausted_credits_block_execution`).

٥. **محاسبة صحيحة بالأعداد الصحيحة** — كل التكاليف محسوبة بـ **ميكرو-دولار**
(عدد صحيح، مفيش أخطاء الفاصلة العائمة). التكلفة → استخدام → رصيد، كلها في نفس المسار.

٦. **تشفير المفاتيح** — كل مفاتيح الربطات ومفاتيح LLM الخاصة بكل شركة
متشفّرة بـ Fernet مشفّر في قاعدة البيانات. المفتاح الرئيسي مفيش في الكود أبداً.

٧. **سجل تدقيق (Audit log)** — كل حركة حسّاسة متسجّلة: مين، إمتى، إيه، منين.

٨. **طابور Outbox متين** — أي عملية خارجية (نشر، إيميل، ويبهوك) بتتسجّل كحدث في جدول
وبتنفّذ مع إعادة محاولة وتأخير تصاعدي، وبتتحوّل لـ `DEAD` بدل ما تضيع.

٩. **فحص ما قبل الإقلاع** — الإنتاج بيرفض يشتغل لو: المفتاح السري لسه الافتراضي،
أو مفيش مفتاح تشفير، أو قاعدة البيانات SQLite في بيئة production.

١٠. **كلمات سر >٧٢ بايت** — bcrypt بيعمل pre-hash بـ sha256 قبل التشفير (نفس المسار في
التسجيل والتحقق)، فمفيش رفض صامت لكلمات السر الطويلة.

| العرض | السبب | الحل |
|---|---|---|

**الحجم:** ٥٨ ملف بايثون · ٩٦٦٤ سطر كود تطبيق · ٢٦ مسار ويب · ٥٩ نقطة API · ١٦ شاشة.

## ٥. الاقتصاد بتاع الوكلاء (السر اللي بيخلي التكلفة تقليلة)

المنصات اللي زي ReStructure بتكلّف آلاف الدولارات لأنها بتشغّل موديل كبير على كل خطوة.
إحنا بنستخدم نفس تركيبة التوفير:

| الدور | الموديل | بيستخدم في |
|---|---|---|
| **التفكير (Thinking)** | موديل كبير (GPT-5 / Claude / Qwen عبر Ollama) | الكتابة، التحليل، التلخيص |
| **القرار (Decision)** | موديل صغير ورخيص | يطلع حكم مكتوب (JSON) — نعم/لا، أي قناة، تقييم من ١٠ |
| **الكود (Code)** | ببلاش | العدّ، الحساب، الفوترة، القواعد |

النتيجة: **أقل من سنت واحد لكل تشغيل** بالموديلات الحقيقية، وصفر بالموديل الوهمي.
كل الحسابات والفوترة بتحصل في كود عادي مش في الموديل.
